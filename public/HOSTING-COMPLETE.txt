# Elysium Hotels — complete Hostinger shared hosting guide
===========================================================

Your live URL: https://elysiumhotel.grootdigitals.com
(subdomain root — assets use /assets/ not /elysium/assets/)

PACKAGE: dist.zip
UPLOAD TO: the subdomain document root for elysiumhotel.grootdigitals.com
  (Hostinger File Manager → that subdomain's folder, usually its public_html)

-----------------------------------------------------------
A) UPLOAD
-----------------------------------------------------------
1. Delete ALL old files in the subdomain root
   (especially delete the whole assets/ folder — old CSS keeps loading otherwise)
2. Extract dist.zip so these sit at the ROOT:
     index.html
     .htaccess
     assets/
     api/
     desk/
     images/
     sitemap.xml
     robots.txt
3. Do NOT nest inside another extra folder
4. In Hostinger → clear LiteSpeed / website cache if enabled
5. Open https://elysiumhotel.grootdigitals.com/
   Hard refresh (Cmd+Shift+R) or test in a private window
6. Verify deploy: View Page Source → confirm
     /assets/styles-*.css
   matches a file that exists in your assets/ folder on the server

-----------------------------------------------------------
B) ADD SECRETS (required — not included in the package)
-----------------------------------------------------------
Edit api/config.php on the server and set:

  database_url   → Neon connection string (console.neon.tech)
  admin_password → password for /desk/ login

Optional neon[] fields (host/user/password) if you prefer splitting
the URL; database_url alone is enough for Desk on shared hosting.

-----------------------------------------------------------
C) CREATE TABLES (required once)
-----------------------------------------------------------
https://elysiumhotel.grootdigitals.com/desk/
Login with admin_password from api/config.php
→ Setup Neon DB → Run database setup
Status should become: Neon connected (HTTPS)

If Desk says "Not connected":
1. Confirm api/config.php has database_url set
2. Run Setup Neon DB again
   (Shared hosting uses Neon over HTTPS — pdo_pgsql is NOT required)
