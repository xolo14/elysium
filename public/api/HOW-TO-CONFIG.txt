EDIT ON HOSTINGER — Neon + Desk
================================

1) File Manager → subdomain root → api/config.php
   (If missing: copy from api/config.example.php)

2) Paste your Neon connection string:

   'database_url' => 'postgresql://USER:PASSWORD@HOST/neondb?sslmode=require',

   Tip: use the pooled connection string from Neon.
   sslmode=require is enough for PHP (ignore channel_binding).

3) Set desk password:

   'admin_password' => 'your-secure-password',

4) Save, then open:

   https://elysiumhotel.grootdigitals.com/desk/

5) Login → SETUP NEON DB → Run database setup

   Status should show: Database: CONNECTED

NOTES
-----
- Bookings save to Neon when config is set (plus local _bookings/ backup).
- Desk password is admin_password in api/config.php (not GitHub).
- Get Neon URL: https://console.neon.tech → Connection string
